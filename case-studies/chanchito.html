Chanchito Aplicación

Una aplicación web full-stack que conecta a los dueños de mascotas con su veterinario: solicitudes de consulta, aprobación y un historial clínico ordenado, todo desde el navegador.

Proyecto
Tesis de grado · Ingeniería en Informática (URBE)
Equipo
Desarrollo en conjunto con un compañero de carrera
Mi rol
Co-desarrolladora full-stack
Stack
Node.js · Express · MySQL · JavaScript · HTML · SCSS · Nodemailer
Código
Repositorio privado (disponible a solicitud)

El problema

En una consulta veterinaria pequeña, las solicitudes llegan por llamadas y mensajes sueltos: se pierden datos, el veterinario no ve de un vistazo qué está pendiente y los dueños no saben en qué estado está su solicitud.

La solución

Una aplicación web con dos perfiles —dueño de mascota y veterinario— que centraliza el proceso de principio a fin.

RegistroEl dueño crea su cuenta e inicia sesión de forma segura.
PacienteRegistra a su mascota (perro o gato) con sus datos.
SolicitudPide una consulta; el veterinario la acepta o la rechaza.
HistorialAmbos consultan el historial de consultas del paciente.

Funcionalidades principales

  • Registro, inicio y cierre de sesión, con sesiones basadas en cookies.
  • Recuperación de contraseña por correo electrónico (Nodemailer).
  • Registro de pacientes y consulta por usuario.
  • Solicitudes de consulta con estado visible: activas, en curso, aceptadas o rechazadas.
  • Historial clínico por paciente y vista de perfil.
  • Interfaz con estilos organizados en SCSS y vistas separadas para cada flujo.

Arquitectura

Navegador (HTML · SCSS · JavaScript) │ login · registro · perfil · solicitud · historial ▼ Servidor Node.js + Express │ rutas REST: /paciente · /solicitudes-por-usuario/:id │ /historial · /verificar-datos · /logout │ middlewares: cookie-parser · method-override ├──► Nodemailer → correos de recuperación de clave ▼ Base de datos MySQL → usuarios · pacientes · solicitudes · historial

Qué aprendí

  • Modelar un proceso real (la consulta veterinaria) como datos, rutas y pantallas.
  • Conectar frontend, API y base de datos en una sola aplicación coherente.
  • Trabajar en equipo con Git: ramas, commits frecuentes e integración de cambios.
  • Diseñar para dos usuarios con necesidades distintas en la misma interfaz.

El código de la tesis se mantiene en un repositorio privado. Si quieres verlo en una entrevista o revisión técnica, escríbeme y te muestro una demo.
